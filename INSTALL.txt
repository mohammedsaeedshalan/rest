🚀 خطوات التثبيت:
─────────────────────────────────────────────────────────────

الطريقة الأولى: التثبيت التلقائي (الأسهل)
───────────────────────────────────────────────

1. افتح PowerShell أو CMD في مجلد المشروع
2. اكتب الأمر التالي:
   
   pip install -r requirements.txt

3. انتظر حتى يتم تثبيت جميع المكتبات
4. شغل التطبيق بالأمر:
   
   python app.py

5. افتح المتصفح واذهب إلى:
   
   http://localhost:5000


الطريقة الثانية: التثبيت اليدوي
───────────────────────────────────────────────

إذا لم تعمل الطريقة الأولى، قم بتثبيت المكتبات يدوياً:

pip install Flask==3.0.0
pip install Flask-SQLAlchemy==3.1.1
pip install Flask-Login==0.6.3
pip install Werkzeug==3.0.1

✅ التحقق من التثبيت:
─────────────────────────────────────────────────────────────

للتأكد من تثبيت Python بشكل صحيح:

python --version

يجب أن يظهر رقم الإصدار (مثل: Python 3.11.0)

للتأكد من تثبيت المكتبات:

pip list

يجب أن تظهر المكتبات التالية:
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Werkzeug

🔧 حل مشاكل التثبيت:
─────────────────────────────────────────────────────────────

❌ المشكلة: "python is not recognized"
✅ الحل: 
   - أعد تثبيت Python وتأكد من تحديد "Add to PATH"
   - أو أضف Python يدوياً إلى متغيرات البيئة

❌ المشكلة: "pip is not recognized"
✅ الحل:
   - استخدم: python -m pip بدلاً من pip
   - مثال: python -m pip install -r requirements.txt

❌ المشكلة: خطأ في الصلاحيات (Permission denied)
✅ الحل:
   - شغل CMD أو PowerShell كمسؤول (Run as Administrator)
   - أو استخدم: pip install --user -r requirements.txt

❌ المشكلة: بطء التحميل
✅ الحل:
   - تحقق من اتصال الإنترنت
   - جرب استخدام مرآة أخرى:
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

🌐 استخدام بيئة افتراضية (اختياري - موصى به):
─────────────────────────────────────────────────────────────

لعزل المكتبات عن النظام الأساسي:

1. إنشاء بيئة افتراضية:
   
   python -m venv venv

2. تفعيل البيئة:
   
   في Windows:
   venv\Scripts\activate
   
   في Linux/Mac:
   source venv/bin/activate

3. تثبيت المكتبات:
   
   pip install -r requirements.txt

4. تشغيل التطبيق:
   
   python app.py

5. لإيقاف البيئة الافتراضية:
   
   deactivate
